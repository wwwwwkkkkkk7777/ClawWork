# Support

ClawWork is community-supported.

- Use GitHub Discussions for usage questions and deployment help when enabled.
- Use the bug report template for reproducible defects.
- Use the feature request template for proposed behavior.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities.

Include the ClawWork revision, operating system, Node.js and pnpm versions,
deployment mode, relevant redacted logs, and reproduction steps. Never post
tokens, passwords, presigned URLs, private files, or personal data.
